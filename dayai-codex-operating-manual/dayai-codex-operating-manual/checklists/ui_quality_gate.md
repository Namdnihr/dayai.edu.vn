# UI Quality Gate

A DAYAI UI change passes only if:

## Design system

- [ ] Uses DAYAI tokens
- [ ] No random colors
- [ ] No random spacing
- [ ] No random radius/shadow
- [ ] Typography hierarchy is clear
- [ ] Components are reused where possible

## Layout

- [ ] PageHeader exists where appropriate
- [ ] Primary action is obvious
- [ ] Whitespace has rhythm
- [ ] Cards have consistent padding
- [ ] Mobile/responsive behavior considered

## Admin

- [ ] Sidebar grouping is logical
- [ ] Table toolbar is clear
- [ ] Search placeholder is specific
- [ ] Status badges are Vietnamese
- [ ] Row actions are not messy
- [ ] Empty/loading/error states exist

## Copy

- [ ] UI text is Vietnamese
- [ ] No Lorem Ipsum
- [ ] No raw enum labels shown to users
- [ ] No broken Vietnamese encoding

## Accessibility

- [ ] Keyboard focus visible
- [ ] Icon-only buttons have labels
- [ ] Inputs have labels
- [ ] Color is not the only status indicator
